# Саяма Exchange — калькулятор валют RUB/USD/THB

Минималистичный SPA-калькулятор валют с синхронизацией курсов между устройствами в реальном времени.

## Возможности

- Конвертация RUB ↔ THB и USD ↔ THB (пара USD ↔ RUB отключена)
- Автоматический пересчёт при изменении полей
- Синхронизация курсов между устройствами через Supabase Realtime
- Админ-панель с парольной защитой (пароль: `1122`)
- Адаптивный дизайн для мобильных устройств
- Поддержка iOS Safari

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка Supabase (для синхронизации курсов)

Следуйте инструкции в [SUPABASE_SETUP.md](./SUPABASE_SETUP.md) — это займёт 5-10 минут.

Кратко:
1. Создайте проект на https://supabase.com
2. Создайте таблицу `rates` (SQL в инструкции)
3. Включите Realtime для таблицы
4. Скопируйте `.env.example` в `.env` и заполните credentials

### 3. Запуск dev-сервера

```bash
npm run dev
```

### 4. Сборка для продакшена

```bash
npm run build
```

Результат будет в папке `dist/`.

## Работа без Supabase

Если не настраивать Supabase — приложение будет работать через LocalStorage, но **без синхронизации между устройствами**. Курсы будут сохраняться только на том устройстве, где их изменил админ.

В консоли браузера вы увидите:
```
Supabase не настроен — работаем через LocalStorage
```

## Доступ к админ-панели

- Кнопка «Настройки курсов» в подвале сайта
- Или горячая клавиша: `Ctrl+Shift+A` (или `Cmd+Shift+A` на Mac)
- Пароль: `1122`
